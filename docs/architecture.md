# 架构说明

本文描述 eink-mini 的确定性结构：数据从哪来、怎么渲染、怎么下发。

## 整体分工

设备是**哑终端**：固件不画页面内容，只负责取位图、显示、按键与配网。

| 环节 | 运行位置 | 说明 |
|---|---|---|
| 时钟页、计时器页 | 设备固件 | 本地渲染，断网可用 |
| 天气、逐小时、月历、单日黄历、赛博木鱼 | 服务端 | 渲染成位图，设备只显示 |
| 页面清单 | 服务端 | 设备启动时拉取，决定有哪些页 |

这样划分的理由：设备没有中文字库，5×7 点阵字模无法承载中文页面；
而时钟和计时器必须脱离服务端独立工作。

## 帧格式

所有服务端渲染的页面最终都转成同一种设备帧：

| 项 | 值 |
|---|---|
| 尺寸 | 296 × 128 |
| 位深 | 1 bpp |
| 行宽 | 37 字节（296 位，MSB first） |
| 整帧 | 4736 字节 |
| 极性 | `1` = 黑 |

整帧长度固定 4736 字节。设备只接受长度完全匹配的帧，不做部分显示。

## 渲染管线

1. 页面在 3 倍画布（888 × 384）上绘制，小字与图标边缘由此获得真实抗锯齿。
2. BOX 降采样回 296 × 128，得到灰度源图。
3. 量化成 1bpp。默认用**硬阈值 165**：阈值越高笔画越粗，
   12px 小字的 1px 宽笔画占比从 61% 降到 31%。
4. Bayer 2×2 / Bayer 4×4 / Floyd–Steinberg 可选，但墨水屏上噪点会咬断笔画，
   默认不启用。
5. 灰阶层（周末网点等）通过页面级 tone 掩码实现，密度取 235/255。

单色墨水屏没有灰阶，屏上看到的层次来自黑色像素之间的物理缝隙。
预览页提供三种视图：人眼视图（面积平均降采样后的灰度）、设备位图、原始灰度。

## 天气数据

- 数据源：Open-Meteo 公开 API，无需密钥。
- 取数在后台线程完成，渲染路径只读缓存。
- 缓存落盘并用 flock 去重，多 worker 下只发起一次实际请求。
- 城市坐标内置常用城市表；地理编码接口不可达时快速失败并降级。
- 取不到数据时显示空值，不显示 0 度的假数据。

## 天气图标

点阵字体没有 ☀ 🌧 ☁ 等字形，Unicode 渲染在目标字号下是豆腐块，
所以图标逐像素手绘，共 11 种（晴 / 晴间多云 / 多云 / 阴 / 雾 / 雨 / 大雨 /
雨夹雪 / 雪 / 雷阵雨 / 雷雹）。

图标在小尺寸下由超采样画布直接降采样得到，轮廓用硬边、内部用 bayer4 抖动。
1px 细斜线在点阵上会碎成噪点，因此只用横、竖、2×2 方块与多边形。

## 单日黄历

服务端用 lunar-python（vendored，MIT）计算，只看当天：

- 公历日期与星期
- 年干支与生肖
- 农历月日
- 日 / 月 / 年干支
- 节气

两条换年换月规则必须精确：

- 年干支按**立春**换年，立春当天即换。
- 月干支按**节气**换月，节气当天即换；上个节气取今天 00:00 之前最后一个，
  下个节气取明天 00:00 之后第一个。

不做农历月历，不做宜忌。

## 固件

| 目录 | 内容 |
|---|---|
| `firmware/src/` | 画布、页面、按键、配网、调度 |
| `firmware/lib/GxEPD2/` | GxEPD2 最小子集（上游，GPL-3.0） |
| `firmware/tools/` | 字体栅格化工具、镜像合并工具、主机端渲染器 |

`firmware/tools/host_render` 能在主机上编译并运行固件的画布与页面代码，
直接输出设备帧格式。这让页面版式可以脱离硬件验证 ——
位图格式的渲染 bug（例如 fillRect 轴向写反）在纯编译检查中查不出来。

## 构建

GitHub Actions 手动触发（`workflow_dispatch`），产物三路分发：

- Actions Artifacts
- `fw-bin` 分支（git 通道）
- GitHub Release 附件

PlatformIO Core 需钉在 6.1.18：6.2.0 带的 SCons 4.11+ 要求被调函数接受
关键字参数，espressif32 的 `get_board_flash_mode(env)` 不匹配，
替换会返回 SCons 的 `_Null` 哨兵并导致 `elf2image` 抛 TypeError。
